Features

Everything you need to download

Packed with power-user features out of the box — no extensions, no premium tiers.

⚡

Multi-Segment Acceleration

Splits files into up to 8 simultaneous segments — like IDM — for maximum download speed over any connection.

🎬

YouTube & Streaming

Download from YouTube, Vimeo, TikTok, Instagram, Twitter and 1000+ sites via yt-dlp. Best quality, auto-merged to MP4.

🌊

Torrent & Magnet Links

Full BitTorrent support with libtorrent. Paste a magnet link or drop a .torrent file — downloads start instantly.

🔄

Dynamic Segment Rebalancing

Intelligent watchdog detects stalled segments and automatically reassigns bandwidth for consistent top speed.

⏸️

Pause & Resume

Pause any download and resume exactly where you left off — even after restarting the app.

🖥️

Native Desktop App

Runs as a true native desktop app using a local web UI — no browser extension or cloud account needed.
